## 完成与未完成的判断规则

1. 代码存在、Mock 通过、供应商互通、部署、业务质量是不同验收层级，分别标记。
2. `capabilities.available` 表示已装配，不保证上游在线；readiness 不保证任意问题可回答。
3. development 得分不能写成泛化准确率；工程测试数量不能写成业务成功率。
4. 接口遗留不阻塞本轮阶段性收口，也不因收口被标记为已完成。
5. 状态更新记录日期、代码/部署版本及证据；复跑方式见[开发指南](development.md)，不复用旧数字冒充新结果。
