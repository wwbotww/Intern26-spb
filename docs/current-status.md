## 完成与未完成的判断规则

1. 代码存在、Mock 通过、供应商互通、部署、业务质量是不同验收层级，分别标记。
2. `capabilities.available` 表示已装配，不保证上游在线；readiness 不保证任意问题可回答。
3. development 满分不能写成泛化准确率；工程测试数量不能写成业务成功率。
4. 需要合同、数据、真实调用授权的任务保持待办，不通过虚构配置或合成数据“关闭缺口”。
5. 状态更新同时记录日期、代码或部署版本和证据位置；其他文档引用本文，不重复记进度。
